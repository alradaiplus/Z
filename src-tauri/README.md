# Z — Desktop (Tauri v2)

A native desktop shell that wraps the Z web app in a Tauri window. Smaller and
faster than Electron, with access to the local filesystem (used by the Markdown
**vault export**, the Obsidian-style local-files mode).

## Prerequisites (on the build machine)

- Rust toolchain (`rustup`)
- Tauri v2 system dependencies for your OS — see
  https://tauri.app/start/prerequisites/ (on Linux: `webkit2gtk-4.1`,
  `libappindicator`, `librsvg`, etc.)
- Node deps installed: `npm install` (pulls `@tauri-apps/cli`)

## Run / build

```bash
# Dev: boots `npm run start` (Next on :3100) and opens the desktop window.
npm run tauri:dev

# Production bundle (.app / .deb / .msi …)
npm run tauri:build
```

The window loads the Next server at `http://localhost:3100` (configured in
`tauri.conf.json` → `app.windows[0].url` and `build.devUrl`). Because Z uses
server features (server actions, Prisma), the desktop app runs alongside the
Next server. `beforeDevCommand` starts it for dev; for a fully self-contained
production app, run the Node server as a Tauri **sidecar** (a packaging step
documented in the Tauri sidecar guide).

## Icons

Placeholder brand-orange icons live in `icons/` (generated by
`npm run icons`). Replace them with real artwork:

```bash
npm run tauri icon path/to/app-icon.png   # regenerates all sizes/formats
```

## Local Markdown vault

The desktop build makes the **"Export workspace to Markdown vault"** command
(Cmd-K) write a real folder of `.md` files to disk, mirroring an Obsidian vault
(nested folders by page hierarchy, YAML frontmatter for title/tags, databases as
Markdown tables).
